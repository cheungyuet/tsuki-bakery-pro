# Tsuki QLD Bakery Pro
> Advanced Industrial Production Management Dashboard v6.0

## 📋 Overview
Tsuki QLD Bakery Pro is a high-performance, tablet-optimized POS and Production Management System designed for industrial bakery environments. Built with React 18 and Vite 7, it focuses on real-time state synchronization and high-visibility UI to streamline workflow in high-noise, fast-paced factory settings.

## 🚀 Key Features
- **Triple-Column Dashboard**: 
Specifically engineered for tablet landscape orientation, providing a comprehensive overview of the entire production floor at a glance.
- **Dynamic Production Workflow:**: 
Live Tracking: Real-time monitoring of the Queue, Active Baking, and Completed batches.
Ad-hoc Scheduling: Supports instant insertion of emergency or custom batches to meet fluctuating production demands.
- **Data Integration**: 
CSV Import Support: Allows managers or marketing teams to bulk-update production schedules via standardized CSV files.
Industrial Presets: Pre-configured oven parameters (Temperature, Time, and Steam) for standardized product lines.
- **Industrial UX Design**: 
Visual Alerts: High-contrast UI and status indicators designed for high-noise, high-activity environments.
Manual Overrides: Quick-access controls for custom batch adjustments.
- **Resilience & Integrity:**: Implementation of robust local persistence to ensure data integrity during network fluctuations.

## 🛠 Tech Stack
- **Framework**: React 18 (Vite 7)
- **Styling**: Tailwind CSS v4 (Utility-first architecture)
- **Icons**: Lucide React
- **Persistence**: Browser LocalStorage for reliable offline-first data handling.

## 📦 Installation & Usage
1. Clone the repository: `git clone https://github.com/cheungyuet/tsuki-bakery-pro.git`
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Build for production: `npm run build`
